VLBI Data Processing
Workflow

From raw antenna recordings at globally distributed stations to published geodetic products at IERS — six processing phases, nine steps.

Observation Correlation Theory & Calibration Pre-processing Estimation Products
Phase 1 · Observation
Radio Telescopes
IVS Network · ~40 stations worldwide

Multiple antennas simultaneously observe the same extragalactic radio source (quasar). Each station samples the incoming wavefront at S- and X-band (legacy S/X, τamb ≈ 50 ns) or broadband 2–14 GHz (VGOS, τamb ≈ 83 ps). An on-site hydrogen maser provides the ultra-stable frequency reference, contributing <1 ps/s instability.

H-maser frequency standard Mark6 recorder S/X dual-band VGOS 2–14 GHz ~8 Gbps data rate
Data Transport
Station → Correlator Centre

Station recordings are shipped physically on Mark6 disk modules (the standard for most sessions) or transferred in real-time via high-speed broadband (e-VLBI). Transit latency determines how quickly EOP products can reach IERS for rapid-turnaround R1/R4 sessions.

Mark6 disk modules (physical) e-VLBI broadband VDIF format
Phase 2 · Correlation
Software Correlator
IVS Correlator Centre · DiFX

The correlator cross-correlates the digitised voltage streams from every station pair (baseline), compensating for geometric path-length differences. Output: complex cross-spectra across all frequency channels per baseline per scan. The group delay observable τ = −dφ/dω is extracted from the spectral phase slope.

DiFX / Mark5 correlator Cross-spectra per baseline Multi-band group delay τ = −dφ/dω → vgosDB v1
Phase 3 · Theory & Calibration
Theoretical Delays
vgosDbCalc · IERS Conventions 2010

vgosDbCalc computes the a priori theoretical delay using the full IERS 2010 model: geometric baseline delay, Earth orientation and precession-nutation, relativistic Shapiro delay, and the a priori hydrostatic tropospheric delay from VMF3 mapping functions. The residual (observed − theoretical) is the analysis input.

VMF3 hydrostatic mapping Earth orientation model Relativistic Shapiro delay Solid Earth tides → vgosDB v2
Instrument Calibration
vgosDbProcLogs · Phase-cal & cable-cal

Station-specific hardware delays are removed: cable-delay calibration corrects signal path variations, phase-cal tones align inter-channel phases, and system temperature (Tsys) measurements calibrate amplitude. An a priori ionospheric model (Global Ionosphere Map) is optionally applied before the analyst takes over.

Cable-cal correction PC-cal phase tones Tsys amplitude calibration GIM ionosphere (optional) → vgosDB v3
Phase 4 · Analyst Pre-processing
Analyst Pre-processing
nuSolve / VieVS · Human-in-the-loop

Three analyst tasks convert the ambiguous multi-band delays into unambiguous picosecond observables ready for parameter estimation:

① Ambiguity resolution — removes the integer-cycle ambiguity (S/X: τamb ≈ 50 ns; VGOS: τamb ≈ 83 ps, effectively eliminated).
② Clock break detection — identifies discontinuous maser jumps and segments the clock polynomial accordingly.
③ Ionospheric calibration — combines S- and X-band delays to remove the dispersive ionospheric contribution: Δτion = (τS−τX)·νS²/(νS²−νX²).

Ambiguity resolution Clock break segmentation S/X ionosphere removal Δτion = (τS−τX)·νS²/(νS²−νX²) → vgosDB v4
Phase 5 · Parameter Estimation
Least Squares Estimation
Weighted LSQ · Normal equation system

Linearised observation equations A·δx = l + v are formed from vgosDB v4 residuals. Time-varying parameters — clocks (60-min nodes), ZWD (30-min nodes), tropospheric gradients GN/GE — use piecewise-linear offsets (PWLO). Stochastic constraints (relative: ZWD ±15 mm/√h; absolute: G = 0 ± 0.5 mm) regularise the PWLO. The normal matrix N = ATPA is solved after imposing NNR/NNT datum conditions to eliminate VLBI's 6 geometric rank deficiencies (3 translations + 3 rotations). Scale is already fixed by c = 299 792 458 m/s.

PWLO clocks — 60 min nodes ZWD + gradients GN/GE NNR / NNT datum N·δx = ATPl Scale fixed by c
Quality Control
Residual analysis · Iterative outlier rejection

Post-fit residuals are inspected for systematic patterns: station-dependent biases, elevation-dependent tropospheric signals, and scan outliers exceeding 3σ. The a posteriori variance factor s₀² = vTPv / (n−u) and the per-station WRMS quantify solution quality. Outliers are down-weighted (SIGMA editing) and the solution is iterated. Target: WRMS ≈ 20–30 ps.

WRMS target: 20–30 ps s₀² ≈ 1.0 (well-conditioned) 3σ outlier rejection Iterative SIGMA editing
Phase 6 · Geodetic Products
VLBI Geodetic Products
IVS Analysis Centres → IERS Bureaux

Session normal equations are reduced (Schur complement: NREDUC = Ngg − Ngl·Nll−1·Nlg) and then accumulated across all IVS sessions spanning decades (Nglobal = Σ Ns,REDUC) to produce multi-year global solutions. VLBI uniquely provides UT1−UTC and celestial pole offsets — quantities no other geodetic technique can deliver — and contributes the metrological scale via c to ITRF.
